## Among our selected station pairs, how do daily high and low temperature distributions differ?

```js
import {boxplot} from "../components/temperature-charts.js";
import {pairs, selectStationRows} from "../components/station-pairs.js";
const distributions = await FileAttachment("../data/q1-temperature-distributions.csv").csv();
const baselines = await FileAttachment("../data/q2-pair-baselines.csv").csv();
```

```js
const pair = view(Inputs.select(pairs, {label: "Station pair"}));
```

```js
const selected = rows => selectStationRows(rows, baselines, pair);
const mainDistributions = distributions.filter(d => d.metric !== "DAILY_RANGE");
```

Daily range uses the difference between the high and low on each day with both observations. It appears in the table as `DAILY_RANGE`.

### Visualization

Boxes span the middle 50% of observations. Lines inside the boxes mark medians. Whiskers extend to the furthest observations within 1.5 interquartile ranges of the box. Every pair uses the same temperature axis.

<div class="card">${resize(width => boxplot(width, selected(mainDistributions), mainDistributions))}</div>

### What the visualization shows

In the Arcata–Des Moines pair, the middle 50% of daily highs spans **55.9–64.0 °F** in Arcata and **46.0–82.0 °F** in Des Moines. The boxes for daily lows also show a wider spread in Des Moines. Its median daily high is warmer, while its median daily low is cooler.
