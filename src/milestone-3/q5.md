## How have temperature extremes changed within each pair over time, and have their average temperatures remained similar?

```js
import {minValidDays, yearlyExtremes, yearlyExtremesFigure} from "../components/yearly-extremes-figure.js";
import {pairs, selectStationRows} from "../components/station-pairs.js";
const daily = await FileAttachment("../data/q0-daily-temperatures.csv").csv();
const baselines = await FileAttachment("../data/q2-pair-baselines.csv").csv();
```

```js
const pair = view(Inputs.select(pairs, {label: "Station pair"}));
```

```js
const stations = selectStationRows(baselines, baselines, pair);
const yearly = yearlyExtremes(daily, stations);
```

### Sample Data Table

Each row is one year. Max, avg and min are the highest, average and lowest daily mean temperature (TEMP) that year. They are blank when the station has fewer than ${minValidDays} valid days in the year.

```js
const [a, b] = stations.map(s => new Map(yearly.filter(d => d.station === s.station).map(d => [d.year, d])));
const f = v => v === null ? "" : v.toFixed(1);
view(Inputs.table([...a.keys()].map(year => ({year: String(year),
  a_days: a.get(year).valid_days, a_max: f(a.get(year).max_f), a_avg: f(a.get(year).mean_f), a_min: f(a.get(year).min_f),
  b_days: b.get(year).valid_days, b_max: f(b.get(year).max_f), b_avg: f(b.get(year).mean_f), b_min: f(b.get(year).min_f),
})), {
  header: {year: "Year",
    a_days: `${stations[0].station} valid days`, a_max: `${stations[0].station} max (°F)`, a_avg: `${stations[0].station} avg (°F)`, a_min: `${stations[0].station} min (°F)`,
    b_days: `${stations[1].station} valid days`, b_max: `${stations[1].station} max (°F)`, b_avg: `${stations[1].station} avg (°F)`, b_min: `${stations[1].station} min (°F)`},
  rows: 6,
}))
```
