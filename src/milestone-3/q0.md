# Q0

## Raw daily temperatures

This page is a working tool for the team, not a research question. It plots each station's raw daily mean temperature so we can see what the data looks like before choosing the aggregate features for Q5 and Q6.

```js
import {dailyTemperatureFigure} from "../components/daily-temperature-figure.js";
import {pairs, selectStationRows} from "../components/station-pairs.js";
const daily = await FileAttachment("../data/q0-daily-temperatures.csv").csv();
const baselines = await FileAttachment("../data/q2-pair-baselines.csv").csv();
const figureState = {span: 0, start: 1985 - 1973};
```

```js
const pair = view(Inputs.select(pairs, {label: "Station pair", value: pairs[1]}));
```

```js
const stations = selectStationRows(baselines, baselines, pair);
```

### Sample Data Table

Each row is one day. Each value is that station's daily mean temperature (TEMP) in °F. A blank cell means the station has no valid value that day.

```js
view(Inputs.table(daily.map(d => ({date: d.date, a: d[stations[0].station_id], b: d[stations[1].station_id]})), {
  header: {date: "Date", a: `${stations[0].station} (°F)`, b: `${stations[1].station} (°F)`},
  rows: 6,
}))
```
