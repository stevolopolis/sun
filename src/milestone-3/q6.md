## How has day-to-day temperature fluctuation changed over time at locations with similar average temperatures?

```js

```

```js
const pair = view(Inputs.select(pairs, {label: "Station pair"}));
```

```js
const stations = selectStationRows(baselines, baselines, pair);
```

### Sample Data Table

Each row is one day. For each station it shows the daily mean temperature (TEMP) and its centered 15-day average, both in °F. A blank cell means the value is missing.

```js
const [a, b] = stations.map(d => d.station_id);
view(Inputs.table(daily.map((d, i) => ({date: d.date,
  aDaily: d[a], aSmooth: smoothed[i][a], bDaily: d[b], bSmooth: smoothed[i][b]})), {
  header: {date: "Date",
    aDaily: `${stations[0].station} daily (°F)`, aSmooth: `${stations[0].station} 15-day (°F)`,
    bDaily: `${stations[1].station} daily (°F)`, bSmooth: `${stations[1].station} 15-day (°F)`},
  rows: 6,
}))
```

### Visualization

Each point is one station-year: the largest absolute difference that year between a day's temperature and the average of the 15 days centered on it. A year with fewer than 300 days where both values exist is left as a gap.
